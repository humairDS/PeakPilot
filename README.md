## PeakPilot

PeakPilot is an Ai Intregrated fitness engine.

# About

Peakpilot is an Ai Integrated Fitness Engine by using Machine Learning Algorithm.


# Features
Ai Integrated System by using Gemini Api.
Generate Diet and Workout plan by your own preferences.
Can Generate Workout and diet plan by regional foods, i.e Engine can generate Desi food diet not just strict diet plan.

Frontend : React / Next.js / Tailwind
Backend	: Python / FastAPI / Flask
